# ArchiFlow 2026 · V11 气候响应建筑游戏实验脚本

**任务源：**《极端天气临时避难单元》概念任务书与用户提供的 A–D 平面对比展板。**研究范围：**俄罗斯伊尔库茨克安加拉河城区滨水区域，**未核实具体地块**。

## 项目原则

- 唯一建筑设计任务书保留在 ArchiFlow 首页；V11 只是同一项目的建筑体验和行为-事件实验模块。
- 保持六项概念净面积为：缓冲入口10㎡、人员停留34㎡、安静休息18㎡、应急照护14㎡、卫生设施10㎡、物资设备14㎡。总和100㎡为概念净面积，**不等于真实建筑面积和合法容纳人数**。
- A 集中热核心、B 线性温度梯度、C 人员/设备分离、D 可变共享核心，根据展板的空间关系重新绘制。**不是矢量化原建筑结构图**。
- 响应技术为 MID / 手动隔断与家具重新布置。固定墙不随天气自动移动；每次动作都需要明确操作者和条件。
- 所有严寒、暴雪、断电、人员峰值均以课堂场景设定为 [H]，除非有时间、位置、来源齐全的实际证据或气象模型数据支持。

## 研究数据层

| 来源 | 已可用内容 | 约束 |
|---|---|---|
| 日本气象厅 JMA ClimatView Irkutsk 30710 | 1月平均气温 −17.6°C、7月19.0°C；站点约 52.27°N,104.32°E | 城市气候常年值，不代表精确项目地块或逐时风雪 |
| Open-Meteo Historical Weather API | 在线请求 2025-01-15 至 2025-01-21 逐时再分析 temperature_2m / wind_speed_10m / snowfall；也可导入下载 JSON/CSV | 必须通过联网调用成功后才能使用历史逐时值；再分析是格点模型估计，不是场地实测 |
| OpenStreetMap / Overpass | 用户确认坐标后可请求参考点 280m 内的建筑、道路与水系 | 志愿者制图，不是权属地籍，不能替代真实地块红线 |
| 学生提供 GeoJSON | WGS84 Polygon 位置、形状和小范围地球表面面积估算 | 必须确认 CRS、来源、红线权属与实测高程 |

**真实物理性能未模拟。** 本游戏模拟空间几何与操作流程，不能声称预测室内温度、通风量、能耗、结构荷载、消防疏散安全、水位、真实室外行人行为。

## 玩家角色

- `STUDENT`：进入不同方案，操作人物视角、选择环境事件、形成比较记录。
- `SHELTER_OPERATOR`：在隔断旁通过 E 操作，完成正常/应急状态变更。
- `CRIT`：规则化检查高密度、隔断操作、红线和证据缺口；给出可解释的暂评分。

## 交互规则

- **W/S** 向前/后，**A/D** 横向移动，左右方向键转向；**鼠标拖动**转动视线。
- 点击 **E / 操作隔断** 或在可动构件附近按键 **E**；玩家必须走近构件，才允许改变状态。
- 选择 A–D 方案，切换“响应前/响应后”；四套方案分别有不同的空间结构和基准评分。
- 选择事件后点击“运行”：游戏建立场景、人物数量与天气视觉，并要求相应人工操作。**人数没有经过使用人数核定**。
- 将导入的气象时间轴移动到某一小时，真实再分析值会改变天气表现；以下触发值仅是脚本试验参数，不是预警标准：`temperature <= -22°C` 候选 E1，`wind >= 30 km/h` 或 `snowfall > 0.5 cm` 候选 E2。
- `E3` 高密度但隔断未操作时，暂时扣9分；人工操作后重新评估。
- `E4` 停电事件暂扣5分，要求人工复核供电和运行安全。

## 六个事件节点

| ID | Trigger | 行为与空间响应 | Crit 检查点 |
|---|---|---|---|
| E0 | 日常低密度使用 | 收纳隔断，布置座凳/桌 | 人员进入与卫生通达 |
| E1 | 低温加剧（课堂或资料驱动） | 门斗错时开门，集中停留，隔离湿衣 | 热工、新风与实际热源缺口 |
| E2 | 强风与雪 | 值守者检查门斗与窗口邻近座位 | 风压、雪漂、入口管理 |
| E3 | 高密度人员集中抵达 | 人工折叠家具，按 E 布置隐私屏 | 交通净宽、噪声、卫生与照护冲突 |
| E4 | 断电/设备故障 | 由人工操作，复核备用照明与能源 | 默认失效状态与人员安全 |
| E5 | 临时应急照护 | 释放入口、增加照护私密屏 | 担架转运、清洁路径、照护视线 |

## 任务完成条件（教学暂定）

1. 在两个方案（推荐 A、D）中完成 E0 与 E3 两轮事件；保存事件 JSON。
2. 人员达到高密度情境时，玩家手动操作隔断，记录改变前后的 Crit；不能把“得分提高”写成可量化的消防合规结论。
3. 至少导入一份**有时间和来源**的历史天气 JSON/CSV，记录站点/网格与真正地块是否一致。
4. 如有真实红线，导入有坐标系统说明的 GeoJSON，在图面解释其与概念建筑包络之间的几何约束。
5. 导出 A/B 等比较 SVG、游戏脚本 JSON、Crit Markdown、SketchUp 可编辑的交换格式 COLLADA `.dae`，并进入 Rhino/SU深化。

## 结构与材料深化方向

1. 门斗：室外湿雪收集、双门错开；材料防滑、易清洁和在低温情况下可靠操作。
2. 可移动隔断：应绘制上轨/铰接点、锁定件、停放位置、碰撞边界，避免在逃生走道中展开。
3. 家具：1800–2000mm 概念行军床、折叠桌、长凳与储物，均须按使用者行为/无障碍规范复核。
4. 冷气候围护：外层耐久、防水透汽、保温连续性、断热及气密细节；材料选型须核对实际性能证明与气候适配性。
