SITE SEARCH / NOT A PRESET LIST

02. 场地由研究问题推导

自行调查任意国家或城市的候选地点。这里不自动宣称某个地方发生过某种灾害；至少记录实际位置、为什么相关以及下一步的数据来源。

网页的地名和经纬度输入不构成地理事实核验。课堂使用时需自行核对官方地图、OpenStreetMap、城市公开 GIS 或教师预置数据包。

AI 可以后续优化语言，但以下字段由学生决定。建筑类型、面积、容积率、结构安全等都不能凭空生成精确指标。

GEOMETRY ENGINE / LINKED MASSING MODEL

06. 从平面直接挤出三维体块

不是 AI 效果图：这里的面和体积由真实的本地几何运算得到。可拖动画布改变观察角度，选择体块高度与层数；导出可编辑 OBJ，用 Rhino / Blender 打开。

INTERACTIVE MASS / 拖拽旋转 · 滚轮缩放

每个功能块为独立几何体。当前模型是概念形体，不代表已完成结构体系、施工构造或空间净高设计。

H / 体块推演：没有真实地形表面、结构参数和日照条件时，软件只计算几何面积和体积，不能声称方案性能更优。
SCHEME HISTORY / A-B-C 方案对比

切换预设时不会自动认定优劣。保存每次平面和体量参数，比较占地、建筑功能面积与空间组织冲突。
